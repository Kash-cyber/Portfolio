Home Credit Default Risk Prediction

My first serious attempt at real-world credit risk modeling — still in progress, still learning every day

View on GitHub Back to Portfolio

Why I Started This (and What I’m Learning)

After finishing the stock visualization project, I wanted something harder — something that actually felt like real data science.

I found the Home Credit Default Risk competition on Kaggle. It’s old (2018), the leaderboard is closed, and it’s known for being one of the toughest tabular datasets out there — over 300,000 rows, 120+ columns, 7 linked tables, and only ~8% positive class. Perfect.

“If I can make sense of this mess, I can handle anything.”

I’m still working on it — slowly, one notebook at a time — because this is the first project where I’m doing everything myself: no tutorial, no copy-paste solutions.

What I’ve Done So Far

  • Loaded and merged all 7 tables (application, bureau, POS, etc.)
  • Created 50+ new features (debt ratios, payment discipline, credit utilization trends)
  • Trained baseline Logistic Regression → Random Forest → XGBoost
  • Reached ~0.78 ROC-AUC locally (still far from top solutions, but improving)

What I’m Learning

  • How messy real financial data actually is
  • Feature engineering is 90% of the battle
  • Class imbalance is brutal (SMOTE, scale_pos_weight, undersampling)
  • Patience — progress is slow, but every run teaches me something

This project isn’t finished. But it’s the one that’s teaching me the most — and honestly, that’s the whole point.
